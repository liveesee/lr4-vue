# ЛР4. FOLIA — Vue

Вариант 4, блоговая платформа. Интерфейс на русском, в палитре лабораторной работы №1. Состояние описано в `data()`, без Pinia и Vuex.

## Запуск

```bash
npm install
npm run dev
```

## Компоненты

- `ArticleList` принимает массив `articles` через `props` и рисует карточки директивой `v-for`.
- `ArticleCard` получает поля статьи через `props` с указанием типа. Счётчик «Нравится» лежит в `data()` и растёт по `@click`. Событие `liked` уходит родителю через `$emit`.
- `CommentSection` связывает поле с `draft` через `v-model`, показывает ошибку через `v-if` и список комментариев через `v-for`. Новый комментарий отправляется событием `comment-added`.

Кнопка «Нравится» в обычном состоянии: иконка и обводка `#8C4A3A`. Высота кнопок и поля — 44 px.
